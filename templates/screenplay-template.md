# 单集剧本填写模板

> 交付格式模板。写完必须过 `python scripts/check_episode.py <文件>`（`--format standard|long|manju`，默认自动分档）。

**先定档位再动笔**（篇幅制式，三选一；规格见 `references/story/series-structure.md` §三）：

| 档位 | 时长（典型值；可调整） | 正文体量【参考·随时长换算】 | 场景 | 单集拍数 | 机检 |
|---|---|---|---|---|---|
| 标准档（默认） | 90～120 秒 | 480～850 / 330～620 | ≤2 | 1 拍（内部 15s 四挡推进） | `--format standard` |
| 长档 | 150～195 秒 | 820～1400 / 660～1150 | ≤3 | 2 拍 + 中段小钩 | `--format long` |
| 漫剧档 | 60～90 秒 | 330～620 | ≤2 | 1 拍 | `--format manju` |

## 一、 标准档 / 漫剧档模板

```text
第【XX】集：【集名/核心爽点标签】
【所属阶段】：第X幕・（第 X/80 集 ｜ 往返第 N 回合・证据档X/反驳档X）
【黄金前3秒钩子】：六母型之一（生死绝境/极端羞辱/身份暴涨/物证背叛/规则悬念/萌系治愈反差）
【冲突形态】：对话型／行动坚持型／身份错位型／关系情感型／规则谜题型／混合（选对骨架与断章公式；**仅行动坚持型放宽机检**，见 references/writing/conflict-design.md）
【叙事承载】：对白主导／动作主导／混合（可选，按实际内容）
【情绪流变】：A ➔ B ➔ C ➔ 结尾
【本集物证】：1~2 个贯穿本集的物件（情绪落点：碗/账本/鱼竿/群聊截图/到账页；特写好拍、AI 生图友好，情绪都落在物证上）
【质疑者配角】：需要时记录具体人物；没有则写无，行动坚持型可另记具体【阻碍来源】
【本集执念】：一句话——本单元/本集要守住或讨回的那件事（与全剧情绪契约同源）
【对手要什么】：反派在本集的即时目标（他图什么、拿什么当筹码）——防"动机悬空"
【本集主角主动目标】：主角本集要做的**选择/行动**（不是被动挨打；节拍卡硬要求）
【本集改变了什么】：信息/关系/资源/位置/危险 至少一项的可见变化
【本集结算】：可辨认变化与阶段兑现；攻防爽剧写反将与对手代价，治愈写关系，悬疑写线索或误判后果
【本集时长】：__ 秒（注明用户目标、ESTIMATED/MEASURED与预算依据；实际话轮、动作、停顿及并行先独立计时，E16只检查代理粗估上界）

[场景]：内景/外景・地点・日/夜        ← 全集 ≤2 个
[人物]：名（状态标签）、名（标签）      ← 名字须在人物账

△ 特写/中景：只写三大视觉锚点（物理结果/身份反差动作/物证亮牌对抗），禁抽象心理词与无效微动作（E26）。
角色名（神态短语：画面词｜语气词）：
"台词。"                              ← 快慢变速（3~6字快刀句 + 8~16字直给算账句），单气口上限 ≤25 字（E2）；每 2~4 句对白必穿插 △ 动作行，连续纯对白 ≤6 行（E24）；物证与大白话结论同轮直给，禁未翻译黑话（E25）

（可选·≤1 处）内心独白：≤25 字，写「具体的账」不写抽象情绪
（可选·≤1 处）旁白：≤12 字，只用于点题转折/时间锚
                                      ← 独白不计对白行；前3秒与断章处禁用；两条独白不得相邻

【本集断章卡点】：画面停格描述。（黑屏：下滑立即解锁第XX集）
```

## 二、 长档模板（150~195 秒弹性）

```text
第【XX】集：【集名/核心爽点标签】（长档·150~195 秒弹性）
【所属阶段】：第X幕・（第 X/40 集 ｜ 单元A ｜ 往返第 N 回合・证据档X/反驳档X）
【黄金前3秒钩子】：六母型之一
【冲突形态】：对话型／行动坚持型／身份错位型／关系情感型／规则谜题型／混合（见 references/writing/conflict-design.md）
【叙事承载】：对白主导／动作主导／混合（可选，按实际内容）
【情绪流变】：A ➔ B ➔ C ➔ D ➔ 结尾
【本集物证】：1~2 个贯穿本集的物件（同标准档；长档建议物证贯穿双回合）
【质疑者配角】：按实际角色填写；行动阻力来自环境时写无并记录【阻碍来源】
【本集执念】：一句话——本单元/本集要守住或讨回的那件事
【对手要什么】：反派在本集的即时目标（他图什么、拿什么当筹码）
【本集主角主动目标】：主角本集要做的**选择/行动**（不是被动挨打）
【本集改变了什么】：信息/关系/资源/位置/危险 至少一项的可见变化
【本集结算】：当前题材的阶段兑现与新压力，不要求所有题材都主角获胜
【本集时长】：__ 秒（先写数值；说明用户目标及ESTIMATED/MEASURED依据）。E16只核编剧粗估上界，不能代替每场实际对白、动作、停顿与顺并行预算；670/800/870字和12～15动作行是示例参考，不是最低字数或动作上限。长档结构仍需双回合和中段小钩，禁止按公式堆字凑时长。
【本集结构】：双回合（回合A ____ ➔ 回合B ____）    ← 时间骨架（弹性·按内容量伸缩）：钩 0~8s / 回合A 8~80s / 小钩≈90s / 回合B 95~170s / 断章 170~195s

[场景]：内景/外景・地点・日/夜        ← 全集 ≤3 个，第 2/3 场必须是升级场（换空间/换对手/换压力等级）
[人物]：名（状态标签）、名（标签）

△ 特写/中景：钩子——直接切入冲突顶点，禁铺垫。
角色名（神态短语：画面词｜语气词）：
"台词。"                              ← 回合A：施压 ➔ 反驳，反驳必须带代价或新信息；对白行 ≥8；每 2~4 句穿插强视觉 △（连续对白 ≤6 行，E24）

【本集中段小钩】：≈90 秒处的新信息/新威胁/反转半步，只抬价不爆点。（机检必查）

△ 中景：回合B —— 升级施压（新证据/新代价/新人证）。
角色名（神态短语：画面词｜语气词）：
"台词。"                              ← 升级反驳/翻盘未遂，禁复读回合A 话术；神态短语规格见 §四
（可选·≤2 处）内心独白：≤30 字，写「具体的账」不写抽象情绪
（可选·≤1 处）旁白：≤12 字，只用于点题转折/时间锚
                                      ← 独白不计对白行；前3秒与断章处禁用；两条独白不得相邻
△ 中景：情绪顶点落地 + 静默反应镜头

【本集断章卡点】：画面停格描述。（黑屏：下滑立即解锁第XX集）
```

结构检查中E19按连续对白块估测密度、E24按连续对白行估测视觉断层，不测真实15秒窗口；实际声画窗口按预算复算。具体写法见[台词工艺](../references/writing/dialogue-craft.md)。

**现实治愈慢档（长档子变体）**：150~195 秒 / **480~850 字**（不是 820~1400），适用治愈系赛道（成年人离婚治愈系、成年人情感/治愈系、银发婚恋）。对白密度低、留白多、空镜多，断章强度降低、情绪密度升高——断章用第五公式"情绪反差落地"（克制型情绪切黑）而非强悬念公式。**不适用标准档/长档的字数上限**，按本变体独立计体量。

**写前**：读台账 + 回合表定位本集档位与拍数；**写后**：更新台账四账 + 按档跑机检。

## 三、填写与复核

此模板用于原创完整单集；定稿短场直接使用[视觉包模板](storyboard-package-template.md)，不补造整集结构。字段中的长度、场数和节拍为所选档位的参考，用户范围与原文事实优先。

神态短语采用“画面词｜语气词”：前者是摄像机可见动作，后者是麦克风可辨发声方式；不写下游不存在的模块或版本号。完整台词方法见[台词工艺](../references/writing/dialogue-craft.md)，独白/旁白配额、禁邻接和声音通道见[声音设计](../references/writing/voiceover-design.md)，具体冲突适配见[冲突设计](../references/writing/conflict-design.md)。

标准和长档时长都从内容预算向上累积，不能先扣口播再平分余额。E16只比较申报与代理粗估×1.20；参考字数和动作行数不是实际片长、最低字数或最高动作配额，完整预算见[预算同步](../references/production/timing-and-sync.md)。

## 四、同项目制作与连续性

需要视觉制作时，在同一项目附[视觉包](storyboard-package-template.md)，完成实际请求范围内的资产、分镜、帧与全部段母稿。台账使用[项目台账模板](project-ledger-template.md)；剧本正文和视觉包共用事实，独白/旁白不计入普通对白行数，视觉包不计入剧本文字体量。
