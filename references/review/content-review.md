# 剧本与视觉内容审阅

本文件约定本包的内容审阅范围，不充当现行法规、平台政策或发行许可清单。发布目标已给定时沿用；未定时仍可完成文字创作。真实拍摄、备案与发布所需的外部要求另按当时适用的官方材料核对，记录版本、日期和适用范围。

## 一、先定位实际材料

写清审的是原文、修订稿、镜头、静帧、声音、特效还是模型母稿。锁定文件与版本，区分画内剧情文字、台词、作者说明和实际媒体。定稿转译先报告命中位置、上下文及受影响的镜头/段，不擅自改台词、结局或人物能力。

## 二、内容检查维度

| 维度 | 审阅问题 | 可讨论的表达调整 |
|---|---|---|
| 暴力与伤害 | 是否用重复、细节化伤害替代冲突因果；效果是否超出已定强度？ | 保留受力、失衡、倒地与行动后果，用反应、遮挡或声音调整呈现；忠实转译先列建议。 |
| 现实危险行为 | 是否把戏剧行动写成可照做的操作步骤，或混淆现实建议与虚构设定？ | 保留剧情结果与必要线索，减少无叙事作用的操作细节。 |
| 性与关系 | 年龄、关系和同意是否清楚；镜头是否额外引入物化或强迫含义？ | 用行动与关系选择表达冲突，不凭镜头改写人物关系。 |
| 未成年人 | 儿童的危险处境、成人议题和行为后果是否被准确呈现？ | 核对角色年龄和具体上下文，避免用自动词替换掩盖问题。 |
| 个人信息 | 身份证件、手机、车牌、地址或屏幕截图是否指向真实私人信息？ | 使用项目内虚构素材；剧情证据的内容和揭示时点保持。 |
| 身份、历史与公共机构 | 是否出现无根据的现实指认、刻板化或把虚构机构冒充真实授权？ | 明确角色与机构设定、材料依据及尚未核验的事实。 |
| 玄幻与民俗 | 虚构世界规则是否清楚，是否被当成现实医疗、投资或操作建议？ | 保留仙侠、斗法与志怪的叙事功能；检查现实语境，不把奇幻设定自动改成骗局。 |
| 价值与后果 | 故事对羞辱、虐待、歧视或报复的态度能否从具体行动和后果判断？ | 复核视角和结算；不为统一口号重写原文或强加“三集受惩”等配额。 |

## 三、本地扫描的能力

`scripts/check_episode.py` 的E10扫描既有高风险词表并可能返回FAIL；它不理解全部上下文，不核验法律，也不能证明未命中内容已通过审核。视觉包的正文、画内文字、声音和特效需同步人工审阅，不能只改剧本里的一个词。

机器FAIL保留其实际结果；若命中来自引用、否定、虚构设定或其他上下文，先核验并说明原因，不为让工具退出0私自改变定稿。建议调整应提供原位置、问题依据、可用改稿及下游影响。用户只要审阅时不自动展开完整制作。

## 四、交付记录

每项记录材料版本、位置、问题、依据、建议及结论。分别标记“本地扫描”“语义审阅”“外部要求已核/未核”“实际平台结果”。只报告真正执行的检查；同义替换、结构通过或泛化的风险提示均不等于平台审核成功。
