# 人物设计与角色记录

人物记录先于其参与的正文。记录深度由角色作用决定；定稿转制作从原文提取，不强行补秘密、弧光或新增关系。

## 一、核心与复现角色

| 项目 | 写什么 | 复核问题 |
|---|---|---|
| 欲望 | 具体想得到、守住或改变什么 | 能否由行动体现，而非只有“想幸福”？ |
| 秘密/软肋 | 隐瞒、误判、脆弱处或行动限制；没有秘密可写无 | 它如何影响选择，谁知道多少？ |
| 变化方向 | 随单元改变的打法、关系或认知 | 静态人物也应使他人或局势改变，不机械强加性格反转。 |
| 语言指纹 | 句长、称谓、用词、气口与表达习惯 | 遮掉名字能否辨认？动作主导角色可以少说话。 |
| 赌注与利害 | 得失、筹码、可承受的代价 | 对手为什么要这样做，行动是否服务其目标？ |

主角、长期对手和复现的重要配角按以上项目建档。反派不统一规定成“刻薄黑话”；语言服从身份、能力、处境和策略。原角色没有某项时如实记录，不把模板当新增剧情许可。

## 二、一次性角色

龙套、传令者、证人或出场即退出的角色只记录名字/称谓、功能、出场集场、对白归属、关键行动与退出/生死事实。其行为影响主线时同步进人物账，不要求独立秘密和成长弧，也不能以“龙套”为由丢掉证言、死亡或持物状态。

同一个人物再次出现时复用身份；戏份扩大后补充档案。具名角色数量按故事负荷控制，常用配额可作参考，不因超过固定人数删除原文角色。

## 三、记录示例

```text
【角色】：林辰，28岁；公开身份为上门女婿，隐藏身份为龙王
【层级】：核心角色
【欲望】：护住妻女，取回主动权
【秘密/软肋】：妻女可能被其身份牵连
【变化方向】：隐忍保护→主动入局→公开承担身份责任
【语言指纹】：短句、少解释、关键时点说出具体条件
【利害】：身份揭示能压制对手，也会暴露家人的位置
【出场/退出】：第1集起；当前状态与证据见同项目台账
```

## 四、角色与事实管理

全员简表记录功能位、首次出场、当前状态和最后变动。核心细节可独立成档，但[项目台账](../../templates/project-ledger-template.md)索引它们并保持同一事实版本。长篇连写只携带当前相关细节；死亡、身份揭示、能力禁忌等仍有效事实不因超过五集丢弃。规则见[连续性管理](continuity-management.md)。
