# 资产图词与单时刻关键帧

本文件补充一体化视觉导演层中的资产执行细节，沿用当前单集的剧本正文、人物圣经、人物账、道具账、世界观规则账和视觉制作账。故事事实只保存一份：视觉资产引用原文锚点和既有事件链，不另建剧情、身份或资源账。场景与动作的执行见 [references/production/storyboard-workflow.md](storyboard-workflow.md)，机制见 [references/fight/fight-mechanics.md](../fight/fight-mechanics.md)，转折与段界见 [references/fight/fight-choreography.md](../fight/fight-choreography.md)。默认自然语言，无须 JSON，也不新增入口或制作阶段。

目录：一、事实与证据；二、人物母图与四视图；三、场景母图；四、道具与复杂武器持有图；五、状态变体；六、关键帧；七、核对与维护来源。

## 一、先分清事实、参考职责和媒体状态

用户给定已定稿原剧本时，身份、关系、持物、伤损、能力、文字内容及揭示顺序以原文和已确认台账为准。视觉层可以细化未规定的机位、服装结构和材质，涉及角色辨识或后续连续性的新增设计须注明依据与暂定范围；不能为了资产丰富而添加武器、伤势、暗号或隐藏能力。原文没有身高、内部结构等事实时保留未知，确需设计则明确为可撤销设计值。

资产的稳定锚点负责识别：脸型、骨相、服装结构、器形、固定地标。持物手、落脚、姿势、新伤、节点亮灭、门的开合是时变状态，记发生事件、适用集场、持续范围和恢复条件。状态目录不表示这些状态同时存在，更不能把结局伤损提前带进开场。

**身高来源**依次采用有效人物档案中的确认值、前期已登记且仍适用的设计值；均无时写未知或另列暂定设计，不从单人照片、构图或鞋底推算厘米。单人母图只写本人身高，人物之间的相对高矮留人物档案和多人视频锚定。巨物、通道和持握比例使用可见参照；未知尺寸不补成精确数字。

每份真实参考只在所属资产或视觉参考记录保存一次来源、版本、职责、允许继承、禁止污染及适用时点，镜头引用该记录：

| 参考职责 | 允许继承 | 必须另行决定或排除的内容 |
| --- | --- | --- |
| 身份 | 已确认的脸、骨相、年龄感、身体比例 | 原背景、棚拍光、姿势、手中非本场物件 |
| 服装与造型 | 衣装结构、妆发、配饰和指定状态 | 不替换身份，不恢复已失去的配饰 |
| 风格 | 媒介、材质、调色、成像与光影语言 | 不复制参考人物、地点、构图，不凭风格改指定色 |
| 空间 | 已看见的地标、结构、通路、机位侧和成立的光源条件 | 不自动带入参考人物、天气、临时破坏 |
| 首帧／尾帧 | 对应时刻的位置、姿态、持物、方向和环境 | 不控制整段运动，不越过原剧情边界 |
| 动作／视频 | 明确指定的运动与节奏 | 不带入其人物身份、武器或命中结果 |

一张图承担多个职责时逐项声明；冲突按用户已给优先级处理，影响身份或胜负的未决冲突列待核。图像未读时只能继承用户明确描述，不能写“参考图中有某种五官、衣纹”。路径读取失败只核对精确路径及直接父目录的文件名、扩展名，不扩大为个人磁盘搜索。

在现有视觉制作账的资产状态行或备注中分项登记证据，无须另建表：

| 状态 | 成立所需证据 | 不可由此推断 |
| --- | --- | --- |
| 提示词已交付 | 本轮完整文本及版本 | 设计已确认或图片已生成 |
| 设计已确认 | 用户确认或已有有效档案 | 媒体已经执行 |
| 媒体已生成 | 对应工具结果、文件或注明为用户报告 | 图片可读、画面正确 |
| 图片可读／已读取 | 文件可访问与实际读取分别记录 | 已上传到当前平台、整片质量通过 |
| 平台可用 | 当前入口中该版本素材实际可选或已上传 | 已绑定本次任务 |
| 本次已提交／已绑定 | 任务记录指向实际素材及其职责 | 生成成功、输出已看过 |

未知写 UNKNOWN，明确未执行才写 NO；用户提供图片的生成过程可以未知。编号、路径、待提供计划不等于图片，上传成功不等于本次提交。仅交付文字时可完成资产提示词；只有本轮目标确实依赖尚缺的图片输入时才阻断相应媒体任务。

以下代码块均为**完整演示提示词**。岑青、168 厘米、石闸院及双月戟是本文演示设计，不是项目事实或未读参考图的观察。迁入项目时依据同一源事实逐项替换，不直接把演示设定写入台账。代码块外的版本、事件编号和证据记录不提交给图像模型。

## 二、人物身份母图与同轮四视图

首次人物资产交付，在同一轮给出身份母图和四视图两份完整提示词，不等母图生成后才补四视图文字。实际出图可以先母图、后以已读取的母图生成四视图；两种顺序不是同一种状态。无图时两份均使用完整文字身份，不虚构上传或绑定。

母图默认 9:16 半身，完整头部至腰部，有合理环境与真实光源。四视图另用横版资产板：**上方脸部特写约占总高度 1/3；下方正面、侧面、背面无头身体图合计约占 2/3**，下方明显更长，禁止等分四宫格。该资产版式与成片视频画幅分别记录：用户仅指定视频画幅，不构成改变人物母图/四视图版式的授权；资产图种未另有要求时沿用以上默认，不重复索取已确定的视频选择。

## 三、场景母图

母图稳定空间结构、地标、通路、高差、材质、时段、天气和光源，不把临时人物或动作写成场景固有内容。门窗、抽屉使用原文规定的起态；原文未定时可选关闭等稳定默认状态并登记。需要开启变体时从已确认结构派生，说明铰链侧、开向及开启程度，不能靠“开门”两字假定模型画对。

```text
风格化三维动画电影的空场景母图，灰石和旧木以哑光材质表现，结构清楚，晨光偏暖，阴影略冷。
场景是山城石闸院，一处东西向长方形通行院落。西侧是入院石阶，东侧灰石墙中央是一扇双扇木闸门，北侧一根完整方石柱，南侧留有连续通道；院内无遮挡住东西通行线的陈设。院墙约为一名成人身高的两倍，石柱与门框同高，保留可供两人错身的南侧通道。
地面为浅灰石板，平整干燥，只在西阶边缘有少量尘土；墙面平整，仅北墙墙脚有两处小磨痕，不画成大面积锈污。木门表面深褐，外侧各有一个黑铁圆环，门板完全闭合，没有破口。东墙除木门外没有窗户、牌匾、告示、相框或文字。
清晨，无雨、无雾。晨光从东南方越过南墙斜照院内，主要照亮北侧石柱的东南面和院中央地面，柱影向西北延伸；灰墙和石板提供弱环境反射，没有灯、术法光或无来源彩光。
摄影机在西侧石阶上方朝东略俯拍，东门、北柱、南通道及西阶边缘同时可辨，景深保证地标和活动区清楚。画面没有人物、武器、临时碎石或剧情破坏，没有画外说明和水印。保留通路和可供后续机位使用的空区，不额外增加庭院、建筑或出口。
```

场景变化按事件登记，例如“C04 打断北柱外沿，碎石进入南通道，C06 的横移不能再走原线”，并给受损变体；不能在后镜恢复空景母图的完整柱体。状态变体只改变已发生的部分，时间与天气另有变化时注明来源。

## 四、核心道具与复杂武器持有图

道具图交代轮廓、部件数量、连接方式、材质、颜色、握持方向、比例与当前状态。归属、适用集场和转交事件记在道具账，生成正文只放看得见的形态。普通道具一张清楚近景足够；复杂武器涉及双手、长柄、链节、特殊护手或多接点时，增加实际持有图验证比例和握法。设定板仅在确需时制作，不为填版虚构内部机械、隐藏能力或变形模式。

## 五、状态变体

先更新文字状态，再按本轮需要出图；湿衣、破袖、少一枚配饰不自动要求新身份母图。换装仍继承身份，新增伤损要有原文事件。人物状态图采用适用四视图或用户指定图种，提示词完整重述当前可见状态；下例演示一种已在文字中确认的雨后破袖状态。


## 六、可独立复制的单时刻关键帧

关键帧是某一时刻的镜头画面，不是人物板或连招示意图。每镜至少一张可读静帧；关键转折补预备、接触、结果三帧，段界补交接帧，具体关系见 [references/fight/fight-choreography.md](../fight/fight-choreography.md)。每帧记录所属镜头、角色 single／prep／contact／result／handoff、全场成片时刻和段内时刻；段内时刻 = 全场时刻 − 段起点。切点帧明确属于哪个镜头和机位，慢镜帧另对齐世界动作阶段。

生成正文完整写出媒介、画幅、实际参考职责、人物身份与当前造型、空间地标、机位、画面位置、姿态、脚下支撑、手与器物、接触点、已有伤损和破坏、实际光源。只描述此刻，不把“跃起、格挡、反击、落地”塞入一张图，也不画尚未发生的裂口或爆炸。场景母图的机位/景别不是永久世界属性；静帧只保留当前一套机位与裁切，不复制历史起幅高度再写覆盖解释。冷却、谋划和未来动作留在导演记录，不画成悬浮文字。

## 七、交付核对与方法来源
