# 验证记录

日期：2026-11-10。当前包为drama-production-studio 6.1.0；视觉文本契约1.2（1.1旧包兼容），战斗JSON契约1.1/1.2。当前环境Python 3.14.6、Windows。

## 6.1.0 变更与检查

本轮处理“视频模型单次生成支持0–30秒之间任意时长”对分段规则的影响。没有引入任意起止、窗口重叠、乱序生成或局部窗口重生成；段仍连续、顺序、沿整镜切分。核心变化是把“段长”从模型上限的附属物，改为按剧本内容与关联关系判断的结果。

- 新增 [内容驱动的分段与时长判断](../references/production/segment-planning.md)：内容闭合、生产闭合、十一维关联图谱、长程依赖、八步决策、硬/软约束、边界稳定性清单、时长计算、特殊情形、案例与记录模板。
- 视觉文本契约升级到1.2：新增【单次生成时长能力】、分段策略、分段决策表、每段【分段依据】、段内多镜母稿写法；1.1旧包继续可读。
- 新增V16分段决策检查：核对能力范围、分段策略、候选比较、每段归组内容/本段时长/边界状态/风险、段长与分段表一致；对“默认/均分/取上限/凑时长”等空泛表述给WARN；不判断叙事合理性。
- 新增 [18秒拆8+10示例](../examples/storyboard-content-segmented.md)，演示同一场为什么不是3×6、不是9+9、也不是30秒整段；旧三段6秒示例保留作短窗口与1.1兼容。
- 模板、台账、预算、摄影提交和斗法契约同步补充“能力是上限、段长由内容判断”的边界说明；README、使用指南和内容地图更新请求示例与检查命令。
- 连续性管理、评测/修订范围与来源归属同步补充分段依据/原创说明；名称映射记录6.1.0新增的参考与示例。
- 分段判断只按时间描述时长：模型支持0–30秒之间任意时长，按实际秒数直接选择；能力记录写“0–30秒之间任意时长”。

程序检查：`verify_package.py` 运行 **235项**，234通过，1项因Windows符号链接创建权限不足跳过；标准档、长档、18秒三段视觉例、1.2内容驱动分段例、6秒忠实斗法例及四套战斗JSON全部退出0；输入SHA在运行前后不变。V16新增用例覆盖：内容驱动分段示例通过、缺分段决策表、缺分段策略、空泛策略WARN、缺分段依据、本段时长与分段表不一致、段长超过能力上限、1.2使用旧能力字段WARN、1.1不要求V16；S9新增新能力字段+分段策略通过、缺策略WARN、空策略WARN。完整命令、退出码与输入SHA见[最终机器报告](verification-results.json)。

## 证据边界

6.0.0整理轮与6.1.0分段修订均没有生成图片、视频或音频，没有演员试读，也没有真实平台审核。片长预算仍为ESTIMATED，结构或对白检查不代表动作语义、媒体质量与实际片长全部通过；V16只证明分段记录存在且不越界，不证明边界和时长在叙事上最优。报告按实际材料和范围记录。
